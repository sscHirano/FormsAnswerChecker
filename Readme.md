# FormsAnswerChecker

Microsoft Forms の回答結果エクセルと回答対象者リストを突き合わせ、**「未回答者」** および **「想定外の回答者」** を自動判定・抽出するデスクトップアプリケーションです。

---

## 📋 主な機能

- **かんたん操作**: Forms の結果エクセルファイルを画面にドラッグ＆ドロップするだけで即座に照合
- **カテゴリ切り替え**: 部署や拠点（大阪社員、東京社員など）ごとに回答対象者リストを切り替え可能
- **未回答者の抽出**: まだ回答していない対象者を一覧表示（Ctrl+C でコピーして催促メール等に即活用可能）
- **想定外の回答者の検知**: 対象者リストに含まれていない人からの回答があった場合に警告表示

---

## 🛠️ 事前準備

`FormsAnswerChecker.exe` と同じディレクトリに `AnswerLists` フォルダを作成し、その中に対象者のメールアドレスを記述したテキストファイル（`.txt`）を配置します。

```text
FormsAnswerChecker/
├── FormsAnswerChecker.exe
└── AnswerLists/
    ├── 全社員.txt
    ├── 大阪社員.txt
    └── 東京社員.txt
```

### 対象者リスト（.txt）の作成ルール
- 1行につき1つのメールアドレスを記述します。
- 空行や空白のみの行は自動的に除外されます。
- ファイル名がそのままアプリ内のカテゴリ選択肢として表示されます。

**記述例（大阪社員.txt）**:
```text
osakaUser1@example.com
osakaUser2@example.com
osakaUser3@example.com
```

## 🚀 使い方

1. **`FormsAnswerChecker.exe` を起動する**
2. **カテゴリを選択する**
   - 画面上部のドロップダウンから照合したい対象カテゴリ（例: `大阪社員.txt`）を選択します。
3. **Forms の回答結果エクセルをドロップする**
   - Forms からダウンロードした結果エクセル（`.xlsx`）をアプリのウィンドウにドラッグ＆ドロップします。
4. **結果を確認する**
   - **全員回答済みの場合**: 「全員回答済み！」のメッセージが表示されます。
   - **未回答者がいる場合**: 未回答者のメールアドレス一覧がダイアログに表示されます。
   - **想定外の回答者がいる場合**: 【警告】として対象者リスト外のメールアドレスが表示されます。

   > **補足**: ダイアログ表示中に `Ctrl + C` を押すと、表示されているメッセージ内容（メールアドレス一覧など）をクリップボードにコピーできます。

---

## 📑 対応エクセル形式

- **Microsoft Forms からダウンロードした標準の回答エクセルファイル（.xlsx）**
  - 1行目: ヘッダー行（自動的にスキップされます）
  - **D列（4列目）**: 回答者のメールアドレス

> **注意**: エクセルファイルを他のソフト（Excel等）で開いたままドロップすると、ファイルアクセスエラーが発生する場合があります。ファイルを閉じてからドロップしてください。

## 🛠️ 開発・ビルド・テスト環境（開発者向け）

### 追加されたファイルとその理由・役割

| ファイル / フォルダ | 役割 | 追加されている理由 |
| :--- | :--- | :--- |
| **`nuget.exe`** | NuGet コマンドラインツール | 本プロジェクト（.NET Framework 4.8）で使用する外部ライブラリ（ClosedXML や MSTest 等）を、Visual Studio がない環境でもコマンドラインから確実に復元（`restore`）できるようにするためです。 |
| **`build.ps1`** | ビルド自動化スクリプト | Windows 標準搭載の MSBuild（`C:\Windows\Microsoft.NET\Framework64\v4.0.30319\MSBuild.exe`）を利用し、**「NuGet パッケージ復元」→「ソリューション全体のビルド」→「実行ファイル（FormsAnswerChecker.exe）の生成確認」** を PowerShell 1 コマンドで完結させるためです。 |
| **`test.ps1`** | 単体テスト自動化スクリプト | Visual Studio のテストエクスプローラー等を使わずに、**「パッケージ復元」→「ビルド」→「MSTest（`vstest.console.exe`）による全テスト実行と合否判定」** をコマンドラインから一括実行するためです。 |
| **`FormsAnswerChecker.Tests/`** | 単体テストプロジェクト | エクセル解析処理（`ExcelParser`）等の判定ロジックの品質担保および回帰テスト（変更時の動作保証）を行うためです。 |

### コマンドの実行方法

PowerShell を開き、リポジトリルートで以下のスクリプトを実行します。

#### 1. アプリケーションのビルド
```powershell
.\build.ps1
```
成功すると `FormsAnswerChecker\bin\Debug\FormsAnswerChecker.exe` が生成されます。

#### 2. 単体テストの実行
```powershell
.\test.ps1
```
パッケージ復元・ビルドが行われた後、全単体テストが実行され、結果がコンソールに出力されます。
